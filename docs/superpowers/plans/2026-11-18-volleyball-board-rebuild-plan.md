# 排球战术板重做计划

## 目标

把项目重做为竖屏手机战术板。教练先在按真实比例缩小的 2D 排球场上编辑站位，再通过关键帧生成 2D 跑位动画和 3D 回放。界面采用蓝色外框、木色球场、号码圆点和底部大尺寸工具栏，所有按钮使用 Godot 原生可点击控件。

## 技术决定

- 继续使用 Godot 4.x、GDScript 和 Android Export Templates。
- 使用原生 `Control` 容器负责 UI，使用独立的球场 `Control` 负责绘制和拖动。
- UI 按竖屏 1080×1920 基准设计，使用安全区和 `Container` 布局适配不同手机尺寸。
- 球场模型固定为 9m × 18m。中线、三米线、端线和边线都从同一个尺寸模型绘制。
- 2D 坐标先转换为米制坐标，再供 3D 使用，避免 2D 和 3D 比例不一致。
- 逐阶段提交和导出 APK，每阶段完成对应验收后再进入下一阶段。

## 分阶段实现

### 第一阶段 竖屏 2D 编辑器外壳

- 将 Android 和项目窗口切换为竖屏。
- 重写根布局为顶部栏、球场区、关键帧区和底部工具栏。
- 绘制真实 9m × 18m 球场，保持 1:2 长宽比。
- 用原生大按钮替代当前自绘按钮。
- 保证按钮点击与球员拖动互不拦截。

验收条件

- APK 启动后保持竖屏。
- 球场纵横比为 1:2，三米线距离中线 3m。
- 底部按钮触控区域不小于 88dp。
- 点击按钮能看到明确的状态变化。

### 第二阶段 球员管理

- 添加球员、号码、姓名和角色。
- 拖动号码圆点修改站位。
- 编辑和删除球员。
- 处理球员重叠和越界提示。

### 第三阶段 关键帧编排

- 第一张关键帧记录初始站位。
- 「下一张」复制上一张全部球员位置。
- 支持关键帧选择、复制、删除和停留时长。
- 显示当前帧到下一帧的方向线。

### 第四阶段 2D 动画

- 按关键帧时长插值移动球员。
- 支持播放、暂停、重播和时间轴拖动。
- 同时启动、先后启动和原地不动保持可见差异。

### 第五阶段 3D 回放

- 使用同一套 9m × 18m 坐标生成 3D 球场。
- 增加木地板、球网、网柱、计分牌、灯光和观众席。
- 复用 2D 关键帧生成球员移动路线。
- 提供斜上方、顶视和网侧机位。

### 第六阶段 球路与动作

- 添加一传、二传、助跑、起跳、挥臂和扣球。
- 添加排球弧线、过网和落点。
- 触球事件与球员关键帧使用统一时间轴。

### 第七阶段 存档和发布

- 关键帧战术保存到 `user://tactics`。
- 重新打开后恢复球员、关键帧和动作。
- 运行 Godot 解析、启动、APK 签名和 Android 安装验收。

## 当前执行范围

第一阶段已完成竖屏 2D 编辑器外壳和真实比例球场。第二阶段已完成球员添加、资料编辑、删除、关键帧新增与删除、战术库新建/打开/删除，以及 3D 回放顶部控制栏调整。后续从第三阶段继续实现更完整的关键帧时长编辑和 2D 动画控制。
